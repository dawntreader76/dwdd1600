PC Parts

What are the parts of a computer and what do they do?

The foundational parts, also known as components, include:

Motherboard
The main circuitboard that connects all the other components together. This part determines what generation of CPU, RAM, and Storage can be used.
Central Processing Unit(CPU)
The CPU is the main "engine" of a computer. It performs incredible amounts of calculations, decodes data, and controls the othe components to perfom tasks.
Random Access Memory(RAM)
This is the short term memory of the computer. When the cpu needs a place to temporarily store data, it is moved to the RAM.
Storage
This is the long term memory of the computer. When a user saves a file, it is stored in storage. There are several types of storage, including fast Solid State Drives(SSD) and more affordable Hard Disk Drives(HDD).
Graphics Processing Unit(GPU)
The GPU is a module that specifically processes graphics data. This is especially useful for 3D modeling, gaming, and even training AI models.
Power Supply Unit(PSU)
This component delivers power to all the other components. It safely converts AC current from the wall into the DC current a computer needs to run smoothly.
Fans and Coolers
Fans and Coolers are critical for a computer to function. For example, the CPU cooler is mounted on top of the CPU to wick away the intense heat it creates, preventing heat damage. Fans mounted inside the computer case pull cool air in, and blow hot air out.
Cases and Housing
This is the outer shell of the computer. It protects the inner components and provides physical buttons for the user to interact with, like power buttons, switches, and sometimes keyboards.

What are peripheral components?

Peripheral components are items users need to interact with or use a computer, but don't impact the core processes of a computer. They typically include:

  • Keyboards
  • Mice
  • Microphones
  • Displays
  • Audio Cards
